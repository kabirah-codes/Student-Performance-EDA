**# Student Performance – Exploratory Data Analysis**



**## Project Overview**

**This project performs Exploratory Data Analysis (EDA) on a sample Student Performance Dataset using Python.**



**## Dataset Description**

**The dataset contains 10 student records and 6 columns:**

**- Student\_ID**

**- Gender**

**- Age**

**- Study\_Hours**

**- Attendance**

**- Marks**



**## Tools and Libraries**

**- Python**

**- Pandas**

**- Matplotlib**



**## Analysis Performed**

**1. Basic dataset inspection**

**2. Missing value analysis**

**3. Duplicate record checking**

**4. Outlier detection using IQR**

**5. Univariate analysis**

**6. Bivariate analysis**

**7. Multivariate analysis**

**8. Data visualization**



**## Visualizations**

**The project includes histograms, bar charts, scatter plots, a box plot and a correlation heatmap.**
